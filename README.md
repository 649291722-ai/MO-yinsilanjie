# MO隐私拦截网（MO Privacy Net）v2.0.7

通用本地隐私拦截网：**任何 AI 可发言的公共平台**（只要发言可被他人观测）都能接入，
出站内容在网络层被机械规则检查，命中即拦截。无平台特判、无私人设定、开关由用户掌控。

---

## 它解决什么问题

AI 靠"自律"检查发言内容，存在极低概率漏网。本插件把检查点下沉到**网络层**：
请求在离开设备前必须经过本地代理，规则引擎逐字检查请求体，
命中敏感规则直接返回 403，内容**物理上无法离开设备**。

## 拦截什么

| 类别 | 内容 |
|---|---|
| NSFW | 性器官词汇、性行为描写 |
| 网络隐私 | IP 地址、内网地址、IP 直连服务器地址 |
| 身份隐私 | 手机号、邮箱、身份证号 |
| 凭据 | API 密钥（sk-…、Bearer、api_key、secret） |
| 路径 | 本地文件路径（/sdcard、/storage、/home 等） |

两级 scope：
- `public`：以上全部拦截（一切可被他人观测的发言出口）
- `internal`：仅拦截硬隐私，放行部署类密钥与服务器地址（服务器部署、后台配置链路）

## 架构

```
AI / MCP 客户端
   │
   ▼  endpoint 指向本地
127.0.0.1:8095/proxy/<route-id>   ← 代理 worker（纯被动）
   │
   ├─ 用户豁免清单命中 ──────────────► 直连放行
   ├─ 总开关 = 关 ──────────────────► 纯转发（平台照常使用）
   ├─ 规则命中 ──► 403 + 拦截日志（内容未出设备）
   └─ 规则放行 ─────────────────────► 转发到平台原站
```

**零负担保证**：代理纯被动接收，无轮询、不主动扫描平台、不重试轰炸、不缓存不重放；
只检查路过本机的请求体；未命中的请求原样转发。

## 如何接入任意平台

平台请求分两类，两条路都能接：

### 方式 A：代理接管（推荐，物理强制）

1. 先点「登记」：扫描本机 MCP 配置，将选中的平台写入本插件
   路由表（仅登记，不改动任何配置）；再点「一键部署」——
   仅将**登记集合内**的 endpoint 指向本地代理并生成路由表；
2. 重启 MCP 服务即可生效；
3. 新平台接入：先「登记」再「一键部署」即可纳入拦截网；
   未登记的配置/平台在任何情况下都不会被触碰或修改。

### 方式 B：检查接口（自集成，适合不走 MCP 的平台）

任何平台包/脚本可在发言前调用本机接口：

```bash
curl -s -X POST http://127.0.0.1:8095/check \
  -d '{"text":"要发送的内容","scope":"public"}'
# → {"allowed":true,"hits":[]}          放行
# → {"allowed":false,"hits":["phone_number"]}  拦截，hits 为命中规则
```

`allowed=false` 时**不要发送**该内容。

## 开关与回退

| 操作 | 效果 |
|---|---|
| 开启拦截 | 内容检查生效 |
| 关闭拦截 | 代理转为**纯转发**，所有平台照常使用，仅跳过检查 |
| 一键回退 | endpoint 全部还原为官方直连 + 停止代理进程，完全无痕 |
| 单条路由开关 | 只影响对应平台 |

## 豁免清单

`/sdcard/Download/Operit/plugins/mo_privacy_net/exempt.json`：

```json
{ "exempt": ["<服务器域名>", "<你的服务器IP>"] }
```

清单中的域名**永不接入代理**、不接管、不检查——适合本地私密服务、可信内网。
可经工具 `add_exempt` / `remove_exempt` 管理，或直接编辑该文件。

## 规则自定义

`/sdcard/Download/Operit/plugins/mo_privacy_net/rules.json` 可自由增删正则规则；
`soft_rules` 保留给未来的提示性规则（不拦截，仅记录）。

## 文件布局

- `packages/mo_privacy_net_tools.js` — 管理工具（status / set_enabled / deploy / rollback / toggle_route / add_exempt / remove_exempt / check / blocked_log / self_check）
- `resources/worker/proxy.js` — 代理 worker（127.0.0.1:8095）
- `resources/rules/default_rules.json` — 默认规则库
- `resources/scripts/deploy.py` / `rollback.py` — 一键部署 / 回退
- `ui/panel/` — WebView 可视化面板

## 隐私声明

本插件**不含任何平台凭据、不含任何平台特判、不含任何作者私人设定**；
路由表与豁免清单生成于使用者的设备本地，凭据仅存于本机（chmod 600）。
代理不收集、不上传任何数据。


## v2.0.7 变更（零 Shizuku 完整版）

- 面板与工具箱取数链路不再依赖系统级执行器：全部改经宿主 UI 通道（http_request）访问本机回环代理（127.0.0.1:8095），任何设备环境均可运行。
- 新增本机回环会话握手（/auth/session，仅 127.0.0.1 可达）：面板凭本机来源换取 30 分钟短效会话令牌，凭据不落面板、不进出网络。
- 管理端点鉴权不变（长效本地令牌 或 有效会话令牌），CORS 仍仅授予本机来源。
- 部署登记采用双源扫描（mcpServers + pluginMetadata）：一键回退后仍可一键完整找回全部已安装平台并重建接管，不依赖回退前登记状态。
- 面板实时显示代理进程存活/运行时长（/state 扩展 alive/pid/uptime）。
- 代理拉起仍以宿主终端能力为最优路径（可用时自动拉起；不可用时由面板内工具/AI 通道按需拉起）。
